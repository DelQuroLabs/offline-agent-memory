# Shared library

Only deliberately reviewed cross-domain knowledge belongs here. All three domains can read eligible shared memory. Keep it concise, useful, and low-sensitivity.

`memory/records/` contains active or proposed shared JSON records. `sources/` contains their supporting evidence. The original requested setup is recorded as the only live starter knowledge. Fictional worked examples are stored elsewhere.

Shared memory cannot be private or restricted in the supplied tool. The sharing playbook requires a separate draft and review. Shared does not mean published on the internet; it means available to every domain in this repository.
