# Weekly maintenance

- Review unprocessed inbox material and remove duplicate copies only with owner authorization.
- Review draft memories for usefulness, evidence, sensitivity, and scope.
- Run the verifier and resolve structural errors before generating new packets.
- Review overdue active memory; renew only after checking the source is still applicable.
- Mark obsolete or contradicted records appropriately.
- Check that closed tasks have a result, a decision record when needed, and a clear next action.
- Inspect accumulated context packets and handle sensitive copies under the retention policy.
- Record one improvement to the process based on an actual failure or success.

Use the maintenance template to record counts and actions. Do not create memory merely to improve a count. A week with fewer, better records can be a successful week.
