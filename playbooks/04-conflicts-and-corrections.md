# Resolve a memory conflict

1. Name the exact disputed claim and collect both source locators.
2. Check whether dates, versions, or contexts explain the disagreement.
3. Mark the unreliable active record disputed while investigating.
4. Ask the Researcher for an evidence comparison, not a vote between agents.
5. Write a corrected draft with precise conditions and a link to the original ID.
6. Put the old same-scope ID in the new record's `supersedes` list and run verify.
7. Review and activate the replacement.
8. Mark the original deprecated and record the reason.

This workflow is manual and should use one writer. If interrupted, inspect both records before continuing. A replacement suppresses an old record only while the replacement is eligible for retrieval, so deprecating the old record prevents stale claims from resurfacing.

If the conflict cannot be resolved offline, preserve the disputed status and explain what new evidence is required.
