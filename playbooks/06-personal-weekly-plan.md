# Personal: a useful weekly plan

Organizer gathers confirmed commitments and active project notes. Planner uses the stated priorities and available time to produce a feasible plan with contingency. Reviewer checks overload, invented dates, and unsupported assumptions. Reflection Analyst may compare the result to previous owner-selected session notes.

Deliverables: a short plan, explicit assumptions, the next action for each priority, and one review point. No external calendar is modified by this workflow. If the owner later wants calendar actions, that is a separate authorized integration.

Memory candidates: an explicit planning preference, a changed project priority, or an owner-endorsed lesson. Keep private details in personal; do not share the whole plan merely because software or business roles exist.
