# Software development and technical research: topic map

These are suggested tags and knowledge areas, not extra security scopes. Use a small vocabulary consistently.

| Tag | Contents |
|---|---|
| `systems` | Component maps, invariants, and dependencies |
| `engineering` | Implementation patterns and local development procedures |
| `debugging` | Reproductions, hypotheses, and verified root causes |
| `research` | Dated technical source comparisons |
| `reference` | Locally saved documentation with version information |
| `experiments` | Reproducible trials with inputs, results, and limitations |

Add a project tag when useful, plus a topic and a record kind. Avoid dozens of near-duplicate tags. Preserve source dates and versions in record bodies, not only in tags.
