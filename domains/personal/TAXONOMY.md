# Personal and work knowledge: topic map

These are suggested tags and knowledge areas, not extra security scopes. Use a small vocabulary consistently.

| Tag | Contents |
|---|---|
| `inbox` | Unprocessed notes and questions |
| `projects` | Bounded outcomes and their deliverables |
| `areas` | Ongoing responsibilities such as household, professional development, or work routines |
| `learning` | Study goals, practice, and demonstrated progress |
| `reference` | Reusable local reference notes |
| `reflection` | Owner-selected journal reviews and practical lessons |

Add a project tag when useful, plus a topic and a record kind. Avoid dozens of near-duplicate tags. Preserve source dates and versions in record bodies, not only in tags.
